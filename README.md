
# Photomap

Photomap is a collaborative, location-based photo mapping web application for fieldwork.

## Features

- Upload JPEG and HEIC photos
- Extract GPS coordinates from photo metadata
- Display geotagged photos on Google Maps
- Manually locate photos without GPS information
- Organize photos by fieldwork region
- Share uploaded photos among participants

## Architecture

- Frontend: React + Vite
- Frontend hosting: GitHub Pages
- Authentication: Firebase Authentication
- Database: Cloud Firestore
- Photo storage: Google Drive
- Backend API: Google Cloud Run
- Maps: Google Maps JavaScript API

## Project structure

- `frontend/` — Web application
- `backend/` — Cloud Run API
